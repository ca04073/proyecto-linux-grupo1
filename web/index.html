Servidor Web del Grupo 1

Nginx sobre Docker · Introducción al Software Libre

El servicio está en línea. Esta página se sirve desde un contenedor nginx y corresponde al proyecto ISL Introducción al Software Libre.

Estado del servicio

  • Servidor HTTP: Nginx
  • Despliegue: Docker (imagen nginx:alpine)
  • Contenido: HTML estático

Software utilizado

Todo el stack está compuesto por software libre:

  • Nginx — servidor HTTP (licencia BSD de 2 cláusulas)
  • Docker Engine — contenedores (Apache 2.0)
  • Alpine Linux — imagen base del contenedor (MIT)

Cómo levantar este sitio

docker build -t servidor-grupo1 .
docker run -d --name nginx-custom -p 8081:80 servidor-grupo1

Luego abrir http://localhost:8081 en el navegador.
